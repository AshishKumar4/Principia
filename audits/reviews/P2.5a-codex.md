## Findings

1. **High — the promised Poincaré action on Schwartz functions is missing.**
   The frozen Poincaré spec assigns this utility to P2.5a
   (`Atlas/Specs/Spacetime/Poincare.lean:45,235`), and the design dossier calls it
   load-bearing (`docs/dossiers/P2-wightman-design.md:42`). P2.5a imports no
   Poincaré module and defines only time reflection. P2.5b's `CovariantField`
   would otherwise require a parallel action path.

2. **High — the committed sign probe's advertised discriminator is false.**
   `audits/probes/P2.5a/time_flip_sign_probe.lean:91` uses exponent arguments
   `+1` and `-1`; `Real.fourierChar` is period one, so both characters equal one.
   The theorem proves only that the arguments differ. Codex compiled both
   `fourierChar 1 = fourierChar (-1)` and the corrected discriminator
   `fourierChar (1/4) ≠ fourierChar (-1/4)`.

3. **Medium — the Reed–Simon normalization attribution is wrong, although the
   Lean kernel formula is correct.** `fourierMinkowski_apply_eq_integral` proves
   `F_eta f(p) = integral exp(-2*pi*i*eta(a,p)) f(a) da`. With physical momentum
   `P=2*pi*p`, this matches the frozen `U(t)=exp(+itH)` convention and Wightman's
   primary-source reconstruction formula with `exp(+i p·xi)` and forward-cone
   support (A. S. Wightman, 2000, pp. 210–211,
   https://ejde.math.txstate.edu/conf-proc/04/w1/wightman.pdf). Reed–Simon II
   §IX.1 instead uses the symmetric `(2*pi)^(-n/2) exp(-i lambda·x)` convention;
   P2.5a is its rescaled inverse transform, not its stated normalization.

4. **Medium — `integrable_smul_of_bounded` overstates its generic contract.**
   The proof establishes `Integrable`, and it is sufficient for `PoincareRep`
   because that structure requires `CompleteSpace H`. The lemma lacks that
   instance while its docstring promises a definite Bochner-integral vector.
   Mathlib defines the Bochner integral as zero for noncomplete codomains
   (`Mathlib/MeasureTheory/Integral/Bochner/Basic.lean:160`). Add
   `[CompleteSpace H]` or weaken the public promise.
